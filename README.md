# Stone Paper Scissors Game

A simple and interactive **Stone Paper Scissors** game built using **HTML, CSS, and JavaScript**.

The player chooses Stone, Paper, or Scissors, and the computer randomly generates its choice. The game then compares both choices and displays the result while keeping track of the score.

## 🕹️ How to Play

1. Choose **Stone**, **Paper**, or **Scissors**.
2. The computer will randomly select one option.
3. The game compares both choices.
4. The winner is displayed on the screen.
5. The score is updated automatically.

### Game Rules

| Player Choice | Beats       |
| ------------- | ----------- |
| 🪨 Stone       | ✂️ Scissors |
| 📄 Paper      | 🪨 Stone     |
| ✂️ Scissors   | 📄 Paper    |

If both the player and computer choose the same option, the game is a **draw**.
